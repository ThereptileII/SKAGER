# Source releases

The public SKAGER source repository is:

https://github.com/ThereptileII/SKAGER

For a distributed binary, obtain its version-specific corresponding-source
archive and source reference from the associated release. Use that reference to
identify the application revision, pinned OpenCPN source, integration patches,
dependency sources and build/install scripts. Public source-snapshot commits
can differ from the private engineering commit recorded in a binary.

The default branch is a maintained source snapshot, not a substitute for an
exact version mapping. See [BUILDING.md](BUILDING.md) for the source layout and
build entry points. Retain the licence texts and copyright notices supplied with
the source and dependencies.

Website, customer accounts and hosted services are separate from this desktop
source distribution. Credentials, customer information and proprietary charts
are not included.
