# Corresponding source scope

This public repository contains the complete corresponding source for the
SKAGER desktop binary: every application/plugin module linked into the product,
its interface/build/install scripts, integration patches, pinned dependency
metadata and applicable license notices.

Private engineering records, CI deployment credentials, web commerce/backend
source, boat-specific logs and proprietary chart content are excluded because
they are not required to build or install the distributed desktop work.

The release page for each binary identifies the exact commit and source archive.
