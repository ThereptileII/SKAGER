# SKAGER corresponding source

This repository contains the minimum maintained source and build material needed
to reproduce the distributed SKAGER desktop integration: application sources,
OpenCPN integration, plugins/modules, installer/build scripts, pinned dependency
metadata, required third-party notices and release documentation.

Internal Jira history, boat logs, design review captures, private web/backend
code, customer data, proprietary chart data, credentials and CI deployment
configuration are intentionally kept in the private engineering repository.
They are not part of the corresponding source for the desktop binary.

OpenCPN is a separate prerequisite and is credited under its GPLv2 terms. The
supported Windows application preserves OpenCPN 5.12.4's Win32/x86 ABI on a
64-bit host. See `docs/release/` and `LICENSE` for source and licensing details.
