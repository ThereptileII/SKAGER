# Installing SKAGER on Windows

## Before installation

Install the supported OpenCPN version separately. Close OpenCPN and SKAGER,
back up your navigation profile, and obtain the official SKAGER installer.
Verify the published checksum where one is supplied.

## Install or update

1. Run Setup.
2. Check the detected OpenCPN installation. Continue only if compatibility is
   confirmed; an unsupported build must not be modified manually.
3. Review the backup and installation locations.
4. Complete installation and launch SKAGER.
5. Verify your charts, routes, waypoints and configured data sources.

Use the maintenance actions supplied by your version for repair, rollback or
uninstall. Keep recovery backups until the installation is working correctly.
Legacy and Safe modes provide recovery options. Portable recovery uses a
separate profile.

See https://beta.skager.app/install/ for requirements and
https://beta.skager.app/support/ for help. Version-specific instructions included
with a release take precedence over this general guide.
