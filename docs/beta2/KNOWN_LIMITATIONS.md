# Beta limitations

SKAGER is beta software and is not a certified navigation system. Consult the
build information and release notes supplied with your exact package.

- Windows integration requires the exact supported OpenCPN installation. The
  supported application and plugin ABI is Win32 on a 64-bit Windows host.
- Portable recovery has an independent profile; installed charts and settings
  are not automatically imported.
- Instruments require valid live sources. Missing and stale values cannot be
  used for dependent estimates.
- Range, arrival energy and SmartNav information are advisory and depend on
  configuration, data quality and conditions.
- Hardware control requires supported equipment and explicit enablement where
  available. No autonomous steering is provided.
- Plugin and Legacy dialogs may retain their original appearance.
- Display, touch, GPU and physical equipment compatibility vary by system.
- Commercial chart licensing remains governed by the chart provider.

Use https://beta.skager.app/support/ for help and current product information.
