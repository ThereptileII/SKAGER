# Portable recovery: start here

Extract the complete portable package into a writable folder. Run the supplied
SKAGER launcher. Use the Legacy or Safe launcher if the main interface cannot
start, closing the previous application first.

The portable package uses its own profile. It does not automatically use charts,
connections or navigation objects from the installed application. Configure
charts you are licensed to use; no commercial chart data is included.

Read the build information and limitations supplied with the exact package.
Unavailable readings are expected when sensors are not connected. No simulated
vessel data is provided by a normal installed build.

For ordinary installation, follow the installation guide. For support, use
https://beta.skager.app/support/ and include the version and a description of the
problem. Review logs for private information before sharing them.
